Decoder Definition & Basic Circuit

Combinational Logic

Exam-Ready Answer Definition

A Decoder is a combinational logic circuit that converts coded binary information from $n$ input lines to a maximum of $2^n$ unique output lines. Each unique binary input combination activates exactly one specific output line (setting it to Logic HIGH '1' for active-high logic), representing the corresponding minterm ($\mathbf{m_i}$) of the input variables. Decoders are fundamental building blocks in digital systems used for memory address decoding, instruction decoding in CPUs, and 7-segment display drivers.

3-to-8 Binary Decoder (Binary-to-Octal)

Block Diagram, Full Truth Table & Logic Circuit Schematic

Comprehensive Exam Answer

A 3-to-8 Decoder (also known as a Binary-to-Octal decoder) takes 3 binary input lines ($A_2, A_1, A_0$) and decodes them into 8 mutually exclusive output lines ($Y_0, Y_1, \dots, Y_7$). When the Enable input ($E$) is active ($E=1$), exactly one output line corresponding to the binary value represented by $(A_2 A_1 A_0)_2$ is driven HIGH ('1'), while all other seven output lines remain LOW ('0'). Each output line represents a fundamental minterm equation: $Y_k = E \cdot m_k$. If $E=0$, all 8 outputs are inhibited to '0'.

03

Enable Control & Decoder Cascading

Functionality of Enable Control

The Enable Control Line ($E$ or $\bar{E}$) acts as a master ON/OFF switch for decoders and demultiplexers. When active ($E=1$ for Active-HIGH, or $E=0$ for Active-LOW), the decoder operates normally, asserting the output line corresponding to the select inputs. When inactive, the enable signal forces all output lines to logic '0' (or logic '1' for active-low outputs), regardless of the input combination.

Decoder Cascading (Expanding Capacity): Enable lines allow small decoders to be cascaded into larger ones. For instance, two 3-to-8 decoders can be combined with one inverter to build a 4-to-16 decoder. The most significant bit ($A_3$) is connected directly to the Enable pin of the upper decoder and inverted ($\bar{A}_3$) to the Enable pin of the lower decoder, selecting which block is active.

Encoder Definition & Basic Circuit Diagram

Exam Answer Paragraph

An Encoder is a combinational digital logic circuit that performs the inverse operation of a decoder. It accepts $2^n$ (or fewer) input lines, where only one input is active at any given moment, and generates a corresponding $n$-bit binary code on its output lines. Encoders are commonly used to compress binary data and encode keypad presses or sensor inputs.

Octal to Binary Encoder (8-to-3)

Octal Encoder Explanation

An Octal-to-Binary Encoder accepts eight input lines ($D_0$ through $D_7$), each representing an octal digit ($0-7$), and produces a 3-bit binary output ($A_2, A_1, A_0$). It is constructed using three 4-input OR gates. Input $D_0$ is not connected to any OR gate because the binary code for octal 0 is $(000)_2$.

Multiplexer (MUX / Data Selector) - Definition & Block Diagram

Terminology Note for Exam:

In digital logic syllabi, the term "Multiplier" often refers to a Multiplexer (MUX) or Data Selector (many-to-one digital switch). Be careful not to confuse MUX with binary arithmetic multipliers ($A \times B$).

Definition Explanation

A Multiplexer (MUX), or Data Selector, is a combinational digital logic circuit that selects binary information from one of many input data lines ($2^n$) and routes it to a single output line ($Y$). The selection of a specific input line is controlled by a set of $n$ selection lines ($\mathbf{S_{n-1}, \dots, S_0}$). A $2^n$-to-1 multiplexer requires $2^n$ data inputs, $n$ select inputs, and 1 output line.

Boolean Function Implementation using MUX

Exam Requirement: Mastering Both Implementation Methods

2 Methods

Any arbitrary Boolean function of $n$ variables can be easily implemented using a $2^{n-1}$-to-1 Multiplexer (or a $2^n$-to-1 Multiplexer). There are 2 standard methods required in exams:

1 Method 1: Direct Variable & Selector Mapping

For a function of $n$ variables (e.g. $F(A,B,C)$):
1. Choose $n-1$ variables as the Selector Inputs ($S_1=A, S_0=B$).
2. Express data inputs ($I_0, I_1, I_2, I_3$) in terms of the remaining variable ($C$), its complement ($\bar{C}$), constant 0 (GND), or constant 1 ($V_{CC}$).

2 Method 2: Implementation Table Method

1. Construct a table with columns representing MUX inputs ($I_0..I_{2^{n-1}-1}$) and rows for variable $C'$ and $C$.
2. Circle the minterms where $F=1$.
3. If no minterm in a column is circled $\rightarrow$ $0$. If both circled $\rightarrow$ $1$. If only top row circled $\rightarrow C'$. If only bottom circled $\rightarrow C$.

Concrete Exam Example Problem:

Problem: Implement the Boolean function F(A, B, C) = ∑ m(1, 2, 6, 7) using a 4-to-1 Multiplexer with $A$ and $B$ connected to select lines $S_1$ and $S_0$.

Demultiplexer (DEMUX / "Demultiplier") -> $2^n$ Outputs

Definition Explanation

A Demultiplexer (DEMUX) is a combinational logic circuit that receives binary information from a single input line ($\mathbf{D}$) and routes it to one of $2^n$ output lines ($\mathbf{Y_0, \dots, Y_{2^n-1}}$), selected by $n$ select lines ($\mathbf{S_{n-1}, \dots, S_0}$). It performs the exact inverse operation of a multiplexer.

Demultiplexer vs Decoder Equivalence ("Need to Make Both")

Equivalence Breakdown

A Decoder with an Enable Input is functionally identical to a Demultiplexer. If the Enable line ($E$) of a $2$-to-$4$ decoder is treated as the Data Input line ($D$), and the decoder's input lines ($A_1, A_0$) are treated as Select Lines ($S_1, S_0$), the decoder behaves exactly as a $1$-to-$4$ Demultiplexer.
