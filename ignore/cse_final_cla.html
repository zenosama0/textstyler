Decoders, Encoders, MUX and DEMUX

Exam study guide with circuits. Notation: A' means NOT A. A is the MSB.

Terminology: "Multiplier" and "Demultiplier" in your syllabus mean Multiplexer (MUX) and Demultiplexer (DEMUX). Do not confuse them with arithmetic multipliers. Write MUX/DEMUX in the exam.

1. Decoder

Definition: A combinational circuit that converts an n-bit binary input into 2n unique output lines. For each input combination exactly one output is HIGH. It is built from AND gates (one per output) and NOT gates.

2 to 4 decoder (n = 2, 4 outputs)

D0 = A'B'   D1 = A'B   D2 = AB'   D3 = AB

2. 3 to 8 Decoder VERY IMPORTANT

3 inputs (A, B, C), 8 outputs (D0 to D7). Each output is a minterm, made with one 3-input AND gate.

3. Enable Control

An enable input (E) switches the decoder on or off. If E = 0 all outputs are 0 (disabled). If E = 1 the decoder works normally. Each AND gate gets one extra input, E.

2 to 4 decoder with enable

Use: enable lets you join small decoders into bigger ones (two 3 to 8 decoders make a 4 to 16 decoder, with the MSB driving the enables). It is also what turns a decoder into a demultiplexer (see section 10).

4. Encoder

Definition: The reverse of a decoder. A combinational circuit with 2n input lines and n output lines. The output is the binary code of the one input that is active. It is built from OR gates. Only one input may be HIGH at a time.

4 to 2 encoder

A1 = D2 + D3   A0 = D1 + D3

Limitations: if two inputs are HIGH together the output is wrong, and D0 = 1 gives 000, the same as no input. A priority encoder fixes both.

6. Multiplexer (MUX)

Definition: A combinational circuit that selects one of many data inputs and sends it to a single output. It has 2n data inputs, n select lines and 1 output. It is a "data selector", many to one.

Y = S1'S0'I0 + S1'S0I1 + S1S0'I2 + S1S0I3

4 to 1 multiplexer: 4 AND gates, 1 OR gate, 2 NOT gates

8. Implementing a Function with a MUX

A 4 to 1 MUX can implement a 3-variable function. Two variables go to the select lines, the third variable (or its complement, 0 or 1) goes to the data inputs. Example: F(A,B,C) = Σm(1, 2, 5, 7).

Type 1: A, B as selectors, C on the input lines

A = S1, B = S0. For each AB pair, compare F at C=0 and C=1: (0,0) gives 0, (1,1) gives 1, (0,1) gives C, (1,0) gives C'.

Steps: 1) Write the truth table. 2) Choose selectors. 3) Make an implementation table (pair the minterms). 4) Read each data input as 0, 1, variable or complement. 5) Connect and draw.

10. Demultiplexer and Decoder: building both

A DEMUX and a decoder with enable are the same circuit. Compare the DEMUX circuit above with the decoder with enable in section 3: only the names differ.

(a) DEMUX built from a decoder

Use the decoder's enable E as the data input, and its inputs A, B as the select lines S1, S0.

(b) Decoder built from a DEMUX

Tie the data input to 1. The select lines become the decoder inputs and the outputs become the minterms.

Decoder: E = 1 gives Dk = minterm k. DEMUX: Yk = D when select = k, else 0. Same AND-gate structure.
