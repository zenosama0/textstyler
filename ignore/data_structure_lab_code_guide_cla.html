Loops, Arrays, Linear Search

Problem 1 - Sum of all integers from 1 to N

Ask the user for a number N, then add up every integer from 1 all the way to N and print the result.
The Core Idea Think of it like stacking blocks. You start with zero blocks (sum = 0), then one at a time you add 1 block, then 2, then 3 ... all the way to N. When you are done, you count the total stack. A for loop is the tool that does the repeating for you. 
#include <stdio.h>

int main() {
    int N, sum = 0;          // (A)
    scanf("%d", &N);           // (B)
    for(int i = 1; i <= N; i++) {  // (C)
        sum += i;               // (D)
    }
    printf("Sum = %d\n", sum); // (E)
    return 0;
}

Line-by-line breakdown

  • A
    int N, sum = 0; Two integer variables are created. N will store the number the user types. sum is the running total - it must start at 0 so that nothing is accidentally added before the loop begins.
  • B
    scanf("%d", &N); This reads a number from the keyboard and stores it in N. The & symbol means "put it at the memory address of N." The %d tells scanf to expect a whole integer.
  • C
    for(int i = 1; i <= N; i++) This is the loop engine. It has three parts separated by semicolons: start (i begins at 1), condition (keep going while i is still less than or equal to N), and step (increase i by 1 after each round). So it counts 1, 2, 3 ... N.
  • D
    sum += i; This is shorthand for sum = sum + i. Every time the loop runs, the current value of i gets added onto whatever sum already holds. After the first round: sum = 1. After the second: sum = 3. And so on.
  • E
    printf("Sum = %d\n", sum); After the loop finishes, this prints the final total. %d is a placeholder that gets replaced by the value of sum. \n moves the cursor to a new line.

Problem 2 - Print array elements in reverse order

A fixed array of 10 numbers is given. Print all elements from the last one back to the first.
The Core Idea An array stores elements in slots numbered 0, 1, 2 ... 9. Normally a loop goes up. To reverse, just make the loop count down instead - start at slot 9, stop at slot 0. 
#include <stdio.h>

int main() {
    int arr[] = {12, 25, 8, 41, 19, 30, 2, 11, 43, 88};  // (A)
    printf("Array Elements in Reverse:\n");
    for(int i = 9; i >= 0; i--) {  // (B)
        printf("%d ", arr[i]);       // (C)
    }
    return 0;
}

Line-by-line breakdown

  • A
    int arr[] = {12, 25, 8, ...}; This creates an array called arr. You don't need to write the size in the brackets because C counts the items inside the curly braces automatically. The first element (12) is at index 0, the last (88) is at index 9.
  • B
    for(int i = 9; i >= 0; i--) The loop starts at 9 (the last valid index), keeps running while i is 0 or more, and decreases i by 1 each round with i--. This is the reverse of the usual loop - it counts down instead of up.
  • C
    printf("%d ", arr[i]); Prints the element at position i. Since i goes 9, 8, 7 ... 0, the elements come out last-to-first. The space after %d separates each number in the output.

Problem 3 - Linear Search

Ask the user for a number (the "key"), then scan through the array one by one to see if the key is there. If found, report its index; if not, say it was not found.
The Core Idea Linear search is like looking for a specific card in a deck by flipping through one card at a time from the top. You check each card, and the moment you find a match you stop. If you reach the end without a match, the card is not there. 
#include <stdio.h>

int main() {
    int arr[] = {12, 25, 8, 41, 19, 30};  // (A)
    int key, found = -1;                 // (B)

    printf("search for number in array: ");
    scanf("%d", &key);                    // (C)

    for(int i = 0; i < 6; i++) {          // (D)
        if(arr[i] == key) {                // (E)
            found = i;
            break;                         // (F)
        }
    }

    if(found != -1)                       // (G)
        printf("Element found at index %d.\n", found);
    else
        printf("Element not found in the array.\n");

    return 0;
}

Line-by-line breakdown

  • A
    The array Defines a fixed list of 6 integers that will be searched through. Indices go from 0 to 5.
  • B
    int key, found = -1; key will hold the number the user wants to find. found starts at -1 which is a "not found yet" signal - since -1 is never a valid array index, it works as a safe placeholder.
  • C
    scanf("%d", &key); Reads the user's search number from the keyboard and stores it in key.
  • D
    for(int i = 0; i < 6; i++) Loops through indices 0 to 5 - every position in the array. The search goes one slot at a time, left to right.
  • E
    if(arr[i] == key) Compares the current element to the key. If they are equal, a match is found. The current index i is saved into found.
  • F
    break; Immediately exits the loop once a match is found. No point checking the rest of the array if the answer is already known.
  • G
    if(found != -1) After the loop, this checks whether found changed from its starting value of -1. If it did, the element was found and we print its index. If it's still -1, nothing matched and we print the "not found" message.

Lab 2
Array Insertion

Problem 1 - Insert element at End / Index 1 / k-th position

Take an existing array and add a new element to it - first at the very end, then at position 1, then at whatever position the user asks for.
The Core Idea Arrays in memory are a fixed line of boxes. To insert a new box in the middle, you must physically slide all the boxes after the target spot one step to the right to make room, then place the new value in the opened-up slot. The end of the array is the only place that needs no sliding. 
#include <stdio.h>

// --- The reusable insert function ---
void insertAtIndex(int arr[], int *size, int index, int item) { // (A)
    if(index < 0 || index > *size) return;  // (B)
    for(int i = *size; i > index; i--) {      // (C)
        arr[i] = arr[i-1];
    }
    arr[index] = item;   // (D)
    (*size)++;           // (E)
}

int main() {

    // --- Part i: Insert at end ---
    int arr1[10] = {23, 4, 12, 66, 45, 7, 39, 18};
    int size1 = 8;
    insertAtIndex(arr1, &size1, size1, 55);  // index = size = end
    printf("i) After inserting 55 at end: ");
    for(int i = 0; i < size1; i++) printf("%d ", arr1[i]);
    printf("\n");

    // --- Part ii: Insert at index 1 ---
    int arr2[10] = {23, 4, 12, 66, 45, 7, 39, 18};
    int size2 = 8;
    insertAtIndex(arr2, &size2, 1, 55);
    printf("ii) After inserting 55 at index 1: ");
    for(int i = 0; i < size2; i++) printf("%d ", arr2[i]);
    printf("\n");

    // --- Part iii: Insert at user-given k ---
    int arr3[10] = {23, 4, 12, 66, 45, 7, 39, 18};
    int size3 = 8, k;
    printf("iii) Enter index to insert: ");
    scanf("%d", &k);
    insertAtIndex(arr3, &size3, k, 55);
    printf("After inserting 55 at index %d: ", k);
    for(int i = 0; i < size3; i++) printf("%d ", arr3[i]);
    printf("\n");

    return 0;
}

Understanding the helper function first

  • A
    void insertAtIndex(int arr[], int *size, int index, int item) This is a function - a named block of reusable code. It takes four inputs: the array, a pointer to its size (int *size means "the memory address where size lives, so changes here affect the original"), the position to insert at, and the new value to insert. Using a function means we don't have to copy-paste the same shifting logic three times.
  • B
    if(index < 0 || index > *size) return; A safety check. If the requested index makes no sense (negative, or beyond the current end of the array), the function exits immediately without doing anything. || means "or."
  • C
    The shifting loop This is the core of insertion. Starting from the last occupied slot and working backwards towards the target index, each element is copied one slot to the right: arr[i] = arr[i-1]. Going right-to-left is essential - if you went left-to-right you would overwrite values before they are moved.
  • D
    arr[index] = item; Now that a gap has been created at the target index (the old value there was shifted right), the new item is placed into that slot.
  • E
    (*size)++; The array is now one element larger, so the size counter is increased by 1. The * is needed because size is a pointer - this updates the actual variable in main(), not just a local copy.

How the three parts use the function

Part i - Insert at end

Calls insertAtIndex(arr1, &size1, size1, 55). Notice index = size1 = 8. The shifting loop's condition i > 8 is never true, so no shifting happens at all. The new value is simply placed at slot 8. This is the fast O(1) case.

Part ii - Insert at index 1

Calls with index = 1. The loop runs from i = 8 down to i = 2, shifting slots 7, 6, 5, 4, 3, 2, 1 each one place right. Then 55 lands at slot 1. All the original elements from index 1 onward are preserved, just shifted.

Part iii - Insert at user-given k

The user types a k, that value is passed as the index. The function is identical - it works for any valid index. The user input of k = 3 causes elements at positions 3, 4, 5, 6, 7 to all shift right by one, and 55 drops into slot 3.

23 4 12 55 66 45 7 39 18
Why size = 10 for the array but only 8 used? The array is declared with space for 10 (int arr1[10]) but only 8 values are filled in. This reserves extra room so insertion doesn't overflow the array's bounds.

Lab 3
Array Deletion

Problem 1 - Delete element at Last / Index 1 / k-th position

Remove a specific element from the array. Handle three cases: delete the last element, the element at index 1, and the element at any user-given index.
The Core Idea Deleting from an array is the mirror image of insertion. Because elements are stored in a continuous block, removing from the middle requires sliding all elements after it one step to the left to fill the gap. Deleting from the end requires no sliding at all. 
#include <stdio.h>

void deleteAtIndex(int arr[], int *size, int index) {  // (A)
    if(index < 0 || index >= *size) return;           // (B)
    for(int i = index; i < *size - 1; i++) {           // (C)
        arr[i] = arr[i+1];
    }
    (*size)--;  // (D)
}

int main() {

    // --- Part i: Delete last element ---
    int arr1[10] = {23, 4, 12, 66, 45, 7, 39, 18};
    int size1 = 8;
    deleteAtIndex(arr1, &size1, size1 - 1);  // index 7 = last
    printf("i) After deleting last element: ");
    for(int i = 0; i < size1; i++) printf("%d ", arr1[i]);
    printf("\n");

    // --- Part ii: Delete index 1 ---
    int arr2[10] = {23, 4, 12, 66, 45, 7, 39, 18};
    int size2 = 8;
    deleteAtIndex(arr2, &size2, 1);
    printf("ii) After deleting index 1: ");
    for(int i = 0; i < size2; i++) printf("%d ", arr2[i]);
    printf("\n");

    // --- Part iii: Delete at user-given k ---
    int arr3[10] = {23, 4, 12, 66, 45, 7, 39, 18};
    int size3 = 8, k;
    printf("iii) Enter index to delete: ");
    scanf("%d", &k);
    deleteAtIndex(arr3, &size3, k);
    printf("After deleting index %d: ", k);
    for(int i = 0; i < size3; i++) printf("%d ", arr3[i]);
    printf("\n");

    return 0;
}

Breaking down the delete function

  • A
    void deleteAtIndex(int arr[], int *size, int index) Same function pattern as Lab 2's insert. It takes the array, a pointer to the size (so changes propagate back), and the index to remove. It returns nothing (void).
  • B
    Bounds check If the index is negative, or if it equals or exceeds the current size, the function exits. >= *size is used here (instead of > in insert) because the last valid index is always size - 1.
  • C
    The left-shift loop Starts at the target index and moves forward. Each element is overwritten by the one to its right: arr[i] = arr[i+1]. This effectively "pulls" all elements from the right of the deleted position one step left, closing the gap. The loop stops before the last element (i < *size - 1) to avoid reading out of bounds.
  • D
    (*size)--; The array is now logically one element smaller. Decreasing size means future print loops won't accidentally print the now-stale last slot. The actual memory isn't freed - the number is still there - but it is treated as outside the array.

How the three parts differ

Part i - Delete the last element

Passes size1 - 1 = index 7 as the target. The shifting loop starts at i = 7, but since the condition is i < size - 1 = 7, it never runs at all. Only the size is decremented. Very fast - no work needed.

Part ii - Delete at index 1

Elements at indices 2, 3, 4, 5, 6, 7 each shift left by one slot. Element at index 1 (the value 4) is overwritten and effectively gone.

Part iii - Delete at user-given k

User enters a number k; that index is removed using the same function. With k = 3, the value 66 is removed and everything to its right slides left.

23 12 66 45 7 39 18
Insert vs Delete - spot the difference: Insert shifts elements right-to-left (backward loop) to make room. Delete shifts elements left-to-right (forward loop) to close the gap. The direction matters to avoid overwriting data before it's been copied.
left-shift loop logical size O(1) vs O(n) deletion pointer to size
Lab 4
Bubble Sort

Problem 1 - Sort array using Bubble Sort

Given a scrambled array of 10 student scores, rearrange them in ascending order using the Bubble Sort algorithm, then print both the original and the sorted version.
The Core Idea Bubble sort works by repeatedly walking through the array and comparing neighboring elements. If two neighbors are in the wrong order, swap them. After each full walk, the largest unsorted value has "bubbled up" to its correct spot at the right end. Repeat for as many passes as needed. 
#include <stdio.h>

int main() {
    int students[10] = {23, 4, 99, 13, 12, 66, 45, 7, 39, 18};
    int n = 10;
    int i, j, temp;           // (A)

    printf("Initial Array: ");
    for (i = 0; i < n; i++) {
        printf("%d ", students[i]);
    }
    printf("\n");

    for (i = 0; i < n - 1; i++) {           // (B) outer loop
        for (j = 0; j < n - 1; j++) {         // (C) inner loop
            if (students[j] > students[j + 1]) {  // (D)
                temp = students[j];                 // (E) swap
                students[j] = students[j + 1];
                students[j + 1] = temp;
            }
        }
    }

    printf("Sorted array: ");
    for (i = 0; i < n; i++) {
        printf("%d ", students[i]);
    }
    printf("\n");

    return 0;
}

Line-by-line breakdown

  • A
    int i, j, temp; i and j are the two loop counters. temp is a temporary holding variable used during swaps - without a temp, swapping two values would cause one to be overwritten and lost.
  • B
    Outer loop: for(i = 0; i < n-1; i++) Controls how many passes are made over the array. For n = 10 elements, 9 passes (n-1) are enough to guarantee everything is sorted. Think of each pass as one "sweep" from left to right.
  • C
    Inner loop: for(j = 0; j < n-1; j++) On each pass, this loop walks j from 0 to 8, comparing the element at j with the element at j+1. The condition j < n-1 stops before the last element so that j+1 never goes out of bounds.
  • D
    if(students[j] > students[j+1]) Checks if the left neighbor is bigger than the right. If it is, they are in the wrong order and need swapping. If the left is already smaller (correct order), nothing happens and j moves on.
  • E
    The three-step swap You cannot swap A and B directly - doing A = B would destroy A's old value. The trick: save A in temp, copy B into A, then copy temp (the old A) into B. All three lines together accomplish the swap safely.
Visualizing one pass: Starting array: 23 4 99 13 ... Compare 23 and 4 - wrong order, swap → 4 23 99 13 ... Compare 23 and 99 - correct order, no swap. Compare 99 and 13 - wrong order, swap → 4 23 13 99 ... After a full pass, 99 has "bubbled" to the far right.

Lab 5
Binary Search

Problem 1 - Search in sorted array using Binary Search

Given a sorted array of 10 integers, find a user-specified key using Binary Search. Print the index if found, or a "not found" message otherwise.
The Core Idea Binary search is like guessing a number between 1 and 100. Instead of guessing 1, 2, 3 ... you guess 50 first. If the answer is higher, you now know it's 51-100 and you guess 75 next. Each guess cuts the remaining options in half. Binary search does exactly this - it only works on sorted arrays because it relies on knowing which half to discard. 
#include <stdio.h>

int main() {
    int arr[10] = {1, 3, 9, 17, 25, 29, 43, 55, 83, 99};
    int low, high, mid, flag = 0, key, index = -1;  // (A)

    printf("Enter the key you want to search: ");
    scanf("%d", &key);

    low = 0;    // (B)
    high = 9;

    while(low <= high) {                  // (C)
        mid = (low + high) / 2;           // (D)
        if(key == arr[mid]) {             // (E)
            flag = 1;
            index = mid;
            break;
        }
        else if(key > arr[mid]) {        // (F)
            low = mid + 1;
        }
        else {                            // (G)
            high = mid - 1;
        }
    }

    if(flag == 1) {                       // (H)
        printf("Element %d is found at index %d\n", key, index);
    } else {
        printf("Element %d is not found in the array\n", key);
    }

    return 0;
}

Line-by-line breakdown

  • A
    Variables declared low and high mark the current search window (left and right boundaries). mid is the calculated middle point. flag starts at 0 (not found). index starts at -1 (unknown). key holds the user's search target.
  • B
    low = 0; high = 9; Sets the initial search boundaries to the full array - index 0 (first element) to index 9 (last element). These will shrink as the search narrows down.
  • C
    while(low <= high) The loop keeps going as long as there is still a valid search range. If low ever goes past high, the search space is empty - the element doesn't exist.
  • D
    mid = (low + high) / 2; Calculates the middle index of the current window. Integer division automatically rounds down. For example, if low = 0 and high = 9, mid = 4.
  • E
    Match found If arr[mid] equals the key, the search is successful. Set flag = 1 to signal success, save the index, and break out of the loop.
  • F
    else if(key > arr[mid]) - low = mid + 1; If the key is larger than the middle element, the key must be in the RIGHT half. Move low up to just past mid, discarding the left half entirely.
  • G
    else - high = mid - 1; If the key is smaller than the middle element, the key must be in the LEFT half. Move high down to just before mid, discarding the right half.
  • H
    Print the result After the loop ends (either by break or by the window shrinking to nothing), check the flag. If it's 1, print the found index. If it's still 0, print the not-found message.
Tracing a search for key = 29 in {1, 3, 9, 17, 25, 29, 43, 55, 83, 99}:
Round 1: low=0, high=9, mid=4 → arr[4]=25. 29 > 25, so low = 5.
Round 2: low=5, high=9, mid=7 → arr[7]=55. 29 < 55, so high = 6.
Round 3: low=5, high=6, mid=5 → arr[5]=29. Match! Return index 5.

Binary vs Linear search - why does it matter? Linear search checks up to N elements in the worst case. Binary search checks at most log2(N). For 1000 elements: linear may check 1000 times; binary checks at most 10 times. The array must be sorted for binary search to work.
