Question 1

1. Decoder — Definition and Circuit

Definition: A decoder is a combinational logic circuit that converts n input lines into as many as 2ⁿ output lines. For each valid binary input combination, exactly one output is activated (in the basic active-high version). Therefore, a decoder can be used to select one of many lines, generate minterms, or convert binary-coded information into one-of-many output form.
Basic 2-to-4 decoder: the input combination selects exactly one output.
Core fact to memorize: n inputs → up to 2ⁿ outputs. A decoder is essentially a minterm generator.

How to draw a decoder in an exam

1
Draw the decoder block and label the input lines.
2
Write the output count as 2ⁿ.
3
For a gate circuit, create complements with NOT gates and feed the proper combinations into AND gates.
4
Label each output with its minterm, such as Y₀=A'B'C', Y₁=A'B'C, etc.
Very Important

2. 3-to-8 Decoder

A 3-to-8 decoder has 3 input lines (A, B, C) and 8 output lines (Y₀–Y₇). Since 2³ = 8, every possible 3-bit input combination corresponds to exactly one output. This is one of the most important circuits to practice drawing.

Block diagram: 3 inputs select one of 8 outputs.
Use the complements A', B', C' and eight 3-input AND gates to create Y₀–Y₇.

Question 3

3. Enable Control

Definition: An enable control input allows a decoder or other combinational circuit to operate only when the enable condition is satisfied. In an active-high enable, E=1 enables normal operation, while E=0 forces all outputs inactive. Enable control is useful when several circuits share a system because it lets us turn a decoder on or off without changing its input data.
Active-high enable example. Some real ICs use active-low enable; always copy the polarity shown in the question.
One-line answer: Enable control is a control input that decides whether the decoder is active or disabled.
Question 4

4. Encoder — Definition and Circuit

Definition: An encoder is a combinational logic circuit that performs the opposite type of operation to a decoder: it converts one active input out of many input lines into a smaller binary code at its output. For a basic encoder, 2ⁿ input lines produce n output lines, assuming only one input is active at a time. Encoders are used in keyboards, interrupt systems, priority selection, and data coding.
An encoder reduces many possible input lines to a compact binary representation.
Important difference: Decoder: few inputs → many outputs. Encoder: many inputs → few outputs.

5. Octal-to-Binary Encoder (8-to-3)

An octal-to-binary encoder has eight input lines labeled D₀ to D₇ and three output lines A, B, C. Because octal digits are 0 through 7, three binary bits are enough to represent every input. When one input is HIGH, the corresponding 3-bit binary code appears at the output.

Question 6

6. Multiplexer (MUX) — Definition, Circuit and Block Diagram

Definition: A multiplexer is a combinational circuit that selects one of many input data lines and connects the selected input to a single output line. The selection is controlled by select lines. For a multiplexer with n select lines, the number of data inputs is 2ⁿ. A MUX is therefore often described as a data selector.
4 inputs require 2 select lines because 2²=4.

General MUX equation

For a 4:1 MUX: Y = I₀S₁'S₀' + I₁S₁'S₀ + I₂S₁S₀' + I₃S₁S₀

This equation is important because it shows that the selected input reaches the output while the unselected input terms become 0.

Question 8 — Important

8. Boolean Function Implementation Using a MUX

When a question asks you to implement a Boolean function using a multiplexer, the main idea is to use select lines for some variables and connect the MUX data inputs to constants or to a remaining variable. For a 4:1 MUX, there are two select lines and four data inputs.

Type 1 — A and B are the selector lines

Suppose the function has three variables A, B, C and we choose A and B as select lines. For each AB combination, inspect the function for C=0 and C=1. The required data input will become one of four forms: 0, 1, C, or C'.

Type 2 — One variable is used as the MUX data input line

A second common implementation method is to use two other variables as selectors and leave B (for example) as the remaining data variable. Then each MUX input can again be 0, 1, B, or B'. This is the same core idea, just with a different choice of selector variables.

9. Demultiplexer — 2ⁿ Rule

Definition: A demultiplexer is a combinational circuit that takes one data input and routes it to one of many output lines, according to the select lines. If there are n select lines, the number of possible output lines is 2ⁿ. Therefore, a 1-to-2 DEMUX has 1 select line, a 1-to-4 DEMUX has 2 select lines, and a 1-to-8 DEMUX has 3 select lines.
A 1-to-4 DEMUX has 1 data input, 2 select lines and 4 outputs.

Notice how these equations look like decoder minterms with an extra data input D. That observation leads directly to the decoder/DEMUX relationship below.

10. Decoder and Demultiplexer — How to Make Both

Make a 3-to-8 Decoder

1
Draw inputs A, B, C.
2
Use NOT gates to create A', B', C'.
3
Make eight 3-input AND gates.
4
Connect one unique combination to each AND gate.
5
Label outputs Y₀ through Y₇.

Make a 1-to-4 DEMUX

1
Draw one data input D and select lines S₁, S₀.
2
Use NOT gates to create S₁' and S₀'.
3
Make four 3-input AND gates.
4
Put D into every AND path.
5
Connect the select combination for Y₀–Y₃ and label the outputs.
Very common exam statement: “A demultiplexer is similar to a decoder except that it has a data input.” This is a useful conceptual answer, because the DEMUX output equations are decoder minterms multiplied by D.

Most likely theory questions

Q: What is a decoder?
A: A decoder is a combinational circuit that converts n binary inputs into up to 2ⁿ output lines, activating the output corresponding to the input code.
Q: Explain a 3-to-8 decoder.
A: It has three inputs and eight outputs. Each of the eight possible 3-bit combinations activates exactly one output, so it can generate all eight minterms of three variables.
Q: What is an encoder?
A: An encoder converts one active input among many input lines into a smaller binary code. A basic 8-to-3 encoder therefore converts one of eight active inputs into a three-bit binary number.
Q: What is a multiplexer?
A: A multiplexer is a data-selector circuit that selects one input from several data inputs and connects the selected input to a single output according to the select-line combination.
Q: What is a demultiplexer?
A: A demultiplexer accepts one data input and routes it to one of several outputs according to the select lines. With n select lines, it provides 2ⁿ possible output destinations.
Q: What is the main difference between a MUX and DEMUX?
A: A MUX performs many-to-one selection, while a DEMUX performs one-to-many routing.
Q: How is a DEMUX related to a decoder?
A: A decoder activates one output based on the select code; a DEMUX does the same routing operation but also has a data input. The selected DEMUX output carries D, while the other outputs remain 0.
