Before memorizing any code

When an exam gives you a programming question, convert the English into a small list of actions.

"calculate a total"Think: accumulator + loop.
"print in reverse"Think: last index → first index.
"search one by one"Think: linear search + comparison.
"insert at index"Think: shift right → place value → size++.
"delete at index"Think: shift left → size--.
"sort using Bubble Sort"Think: nested loops + adjacent swap.
"search sorted array"Think: Binary Search + low/high/mid.

Important beginner rule: C arrays start at index 0. For an array of size n, the last valid index is n - 1.

Lab 1

Loops, Reverse Traversal, and Linear Search

Problem 1

Summation from 1 to N

Problem statement: Write a C program to calculate the summation of all integers from 1 to N using a loop, where N is given by the user.

1. How to recognize the solution from the question

  • Look for three things in the question: a user-provided limit N, repeated numbers from 1 through N, and a total/sum.
  • That naturally suggests an accumulator variable (start at 0) and a loop that visits every number.
  • Because the sequence begins at 1 and ends at N, a for loop is a very direct match.

2. Code

#include <stdio.h>

int main() {
    int N, sum = 0;
    scanf("%d", &N);

    for(int i = 1; i <= N; i++) {
        sum += i;
    }

    printf("Sum = %d\n", sum);
    return 0;
}

3. What each important part does

Code / partWhy it is written this way
#include <stdio.h>Includes the standard input/output library so functions such as scanf() and printf() can be used.
int main()The main function is where the program starts running. int means it returns an integer value.
int N, sum = 0;N stores the upper limit entered by the user. sum is the accumulator: it starts at 0 because nothing has been added yet.
scanf("%d", &N);Reads an integer from the keyboard. %d means integer, and &N gives scanf the memory address where it should store the input.
for(int i = 1; i <= N; i++)This loop starts at 1, keeps going while i is at most N, and increases i by 1 after each iteration.
sum += i;Adds the current loop number to the running total. This is shorthand for sum = sum + i;.
printf("Sum = %d\n", sum);Prints the final value stored in sum.
return 0;Ends the program and conventionally reports successful execution.

4. Think through one example

For N = 5: sum starts 0 → add 1 = 1 → add 2 = 3 → add 3 = 6 → add 4 = 10 → add 5 = 15.

5. Rebuild recipe

  1. Create the input variable N.
  2. Create sum and initialize it to 0.
  3. Loop from 1 through N.
  4. Add the current loop variable into sum.
  5. Print sum.
Problem 2

Print an Array in Reverse

Problem statement: Write a C program to print the elements of an array in reverse order.

1. How to recognize the solution from the question

  • The array has 10 elements, so valid indices are 0 through 9.
  • To print backward, start at the last index and move toward index 0.
  • The main trick is not changing the array at all; only the order of accessing its indices changes.

2. Code

#include <stdio.h>

int main() {
    int arr[] = {12, 25, 8, 41, 19, 30, 2, 11, 43, 88};

    printf("Array Elements in Reverse:\n");

    for(int i = 9; i >= 0; i--) {
        printf("%d ", arr[i]);
    }

    return 0;
}

3. What each important part does

Code / partWhy it is written this way
int arr[] = {...};Creates an integer array and initializes it with the values from the question. The compiler can determine the array size from the initializer.
i = 9The final element is at index 9 because the array has 10 elements and indexing starts at 0.
i >= 0The loop must continue until index 0 is printed.
i--Decreases the index by 1 each time, so the access order becomes 9, 8, 7, ..., 0.
arr[i]Reads the element at the current index. The array itself is not rearranged.

4. Think through one example

Access order: arr[9] = 88 → arr[8] = 43 → arr[7] = 11 → ... → arr[0] = 12.

5. Rebuild recipe

  1. Count the array elements.
  2. Find the last valid index: size - 1.
  3. Start the loop there.
  4. Continue while the index is >= 0.
  5. Decrease the index each iteration and print arr[index].
Problem 3

Linear Search

Problem statement: Search for a given key in an array using Linear Search. Print its index if found; otherwise print a not-found message.

1. How to recognize the solution from the question

  • Linear Search means checking the elements one by one from the beginning.
  • You need a key variable for the value being searched.
  • You also need a way to remember whether a match was found. Here, found = -1 conveniently means 'not found yet' because valid array indices are 0 or greater.
  • As soon as a match is found, break stops unnecessary searching.

2. Code

#include <stdio.h>

int main() {
    int arr[] = {12, 25, 8, 41, 19, 30};
    int key, found = -1;

    printf("search for number in array: ");
    scanf("%d", &key);

    for(int i = 0; i < 6; i++) {
        if(arr[i] == key) {
            found = i;
            break;
        }
    }

    if(found != -1)
        printf("Element found at index %d.\n", found);
    else
        printf("Element not found in the array.\n");

    return 0;
}

3. What each important part does

Code / partWhy it is written this way
int key, found = -1;key stores what the user wants to search for. found stores the answer index. Starting at -1 gives a special value meaning 'no match found'.
scanf("%d", &key);Reads the search value from the user.
for(int i = 0; i < 6; i++)Visits every valid index of this 6-element array: 0, 1, 2, 3, 4, 5.
if(arr[i] == key)Compares the current array element with the requested key. Notice the double equals ==, which means comparison; a single = would assign a value.
found = i;Stores the index where the match occurred.
break;Immediately leaves the loop because the required element has already been found.
if(found != -1)Checks whether the special 'not found' value was replaced by a real index.

4. Think through one example

Searching for 19 checks 12 → 25 → 8 → 41 → 19. At 19, found becomes 4 and the loop stops.

5. Rebuild recipe

  1. Store the array.
  2. Read the key.
  3. Use a loop from index 0 to size - 1.
  4. Compare arr[i] with key.
  5. If equal, save i and break.
  6. After the loop, test whether the saved index is still -1.
Lab 2

Array Insertion

Problem 1

Insert at End, Index 1, or Any Index

Problem statement: Given students[10] = {23, 4, 12, 66, 45, 7, 39, 18}, insert 55 at the end, at index 1, and at a user-selected index.

1. How to recognize the solution from the question

  • The physical array has capacity 10, but only 8 positions are currently occupied. Therefore you must track the logical size separately from the array capacity.
  • Insertion at an index other than the end requires shifting existing elements one position to the right to make a hole.
  • A reusable function is useful because all three tasks are really the same operation: insert one item at a specified index.

2. Code

#include <stdio.h>

void insertAtIndex(int arr[], int *size, int index, int item) {
    if(index < 0 || index > *size) return;

    for(int i = *size; i > index; i--) {
        arr[i] = arr[i-1];
    }

    arr[index] = item;
    (*size)++;
}

int main() {
    int arr1[10] = {23, 4, 12, 66, 45, 7, 39, 18};
    int size1 = 8;
    insertAtIndex(arr1, &size1, size1, 55);

    printf("i) After inserting 55 at end: ");
    for(int i = 0; i < size1; i++) printf("%d ", arr1[i]);
    printf("\n");

    int arr2[10] = {23, 4, 12, 66, 45, 7, 39, 18};
    int size2 = 8;
    insertAtIndex(arr2, &size2, 1, 55);

    printf("ii) After inserting 55 at index 1: ");
    for(int i = 0; i < size2; i++) printf("%d ", arr2[i]);
    printf("\n");

    int arr3[10] = {23, 4, 12, 66, 45, 7, 39, 18};
    int size3 = 8, k;

    printf("iii) Enter index to insert: ");
    scanf("%d", &k);

    insertAtIndex(arr3, &size3, k, 55);

    printf("After inserting 55 at index %d: ", k);
    for(int i = 0; i < size3; i++) printf("%d ", arr3[i]);
    printf("\n");

    return 0;
}

3. What each important part does

Code / partWhy it is written this way
void insertAtIndex(...)Creates one reusable function so the insertion logic does not need to be rewritten three times.
int arr[]Receives the array. Arrays are passed to functions in a way that lets the function modify the original array.
int *sizeA pointer to size is used because the function must change the original size variable in main. This lets (*size)++ update it.
if(index < 0 || index > *size) return;Rejects invalid indices. Index equal to size is allowed because that means inserting immediately after the current last element.
for(int i = *size; i > index; i--)Starts at the first empty position and moves backward. Going backward is important so that values are not overwritten before they are copied.
arr[i] = arr[i-1];Copies each existing value one place to the right.
arr[index] = item;Places the new item into the hole that was created.
(*size)++;Increases the logical number of used elements by one.
insertAtIndex(arr1, &size1, size1, 55)For end insertion, the target index is the current size. Example: with size 8, the new item goes at index 8.
insertAtIndex(arr2, &size2, 1, 55)Targets index 1, so elements currently at indices 1 through 7 are shifted right.
scanf("%d", &k)Lets the user choose the insertion index for part iii.

4. Think through one example

Insert 55 at index 3 into [23,4,12,66,45,7,39,18]. Shift 18→9, 39→8, 7→7, 45→6, 66→5. Then place 55 at index 3.

5. Rebuild recipe

  1. Keep both capacity and logical size in mind.
  2. Validate the target index.
  3. Start from the end of the used portion.
  4. Shift elements right until the target position is open.
  5. Put the new value at the target.
  6. Increase size.
  7. Remember: this only works if there is unused capacity.
Lab 3

Array Deletion

Problem 1

Delete Last, Index 1, or Any Index

Problem statement: Delete the last element, delete the element at index 1, and delete the element at a user-selected index from the given array.

1. How to recognize the solution from the question

  • Deletion from an array changes the logical contents, so track size separately.
  • If the deleted element is in the middle, the values after it must move left to close the gap.
  • For the last element, no shifting is needed; decreasing the logical size is enough.
  • A single deleteAtIndex function can handle all three cases.

2. Code

#include <stdio.h>

void deleteAtIndex(int arr[], int *size, int index) {
    if(index < 0 || index >= *size) return;

    for(int i = index; i < *size - 1; i++) {
        arr[i] = arr[i+1];
    }

    (*size)--;
}

int main() {
    int arr1[10] = {23, 4, 12, 66, 45, 7, 39, 18};
    int size1 = 8;
    deleteAtIndex(arr1, &size1, size1 - 1);

    printf("i) After deleting last element: ");
    for(int i = 0; i < size1; i++) printf("%d ", arr1[i]);
    printf("\n");

    int arr2[10] = {23, 4, 12, 66, 45, 7, 39, 18};
    int size2 = 8;
    deleteAtIndex(arr2, &size2, 1);

    printf("ii) After deleting index 1: ");
    for(int i = 0; i < size2; i++) printf("%d ", arr2[i]);
    printf("\n");

    int arr3[10] = {23, 4, 12, 66, 45, 7, 39, 18};
    int size3 = 8, k;

    printf("iii) Enter index to delete: ");
    scanf("%d", &k);

    deleteAtIndex(arr3, &size3, k);

    printf("After deleting index %d: ", k);
    for(int i = 0; i < size3; i++) printf("%d ", arr3[i]);
    printf("\n");

    return 0;
}

3. What each important part does

Code / partWhy it is written this way
if(index < 0 || index >= *size) return;The valid indices are 0 through size-1. An index equal to size is already outside the used portion, so it is rejected.
for(int i = index; i < *size - 1; i++)Starts at the deleted position and continues until the element immediately before the old last position.
arr[i] = arr[i+1];Copies every following value one place to the left, filling the deleted element's position.
(*size)--;Reduces the logical number of elements by one. The old final cell may still physically contain a value, but it is no longer part of the array's used portion.
size1 - 1For size 8, the last valid index is 7. This expression avoids hard-coding 7 and directly represents 'last index'.

4. Think through one example

Delete index 3 from [23,4,12,66,45,7,39,18]: copy 45→index3, 7→index4, 39→index5, 18→index6, then reduce size from 8 to 7.

5. Rebuild recipe

  1. Validate the index: 0 <= index < size.
  2. Start at the deleted index.
  3. Shift every later element one place left.
  4. Decrease size.
  5. For the last element, the loop performs zero shifts and only size decreases.
Lab 4

Bubble Sort

Problem 1

Sort Ten Integers Using Bubble Sort

Problem statement: Sort an array of ten student scores using Bubble Sort and display the initial and final arrays.

1. How to recognize the solution from the question

  • Bubble Sort repeatedly compares neighboring elements.
  • If the left element is larger than the right element, swap them.
  • One full pass pushes a large value toward the right side. Repeating enough passes sorts the whole array.
  • Swapping needs a temporary variable so one value is not lost.

2. Code

#include <stdio.h>

int main() {
    int students[10] = {23, 4, 99, 13, 12, 66, 45, 7, 39, 18};
    int n = 10;
    int i, j, temp;

    printf("Initial Array: ");
    for (i = 0; i < n; i++) {
        printf("%d ", students[i]);
    }
    printf("\n");

    for (i = 0; i < n - 1; i++) {
        for (j = 0; j < n - 1; j++) {
            if (students[j] > students[j + 1]) {
                temp = students[j];
                students[j] = students[j + 1];
                students[j + 1] = temp;
            }
        }
    }

    printf("Sorted array: ");
    for (i = 0; i < n; i++) {
        printf("%d ", students[i]);
    }
    printf("\n");

    return 0;
}

3. What each important part does

Code / partWhy it is written this way
int students[10] = {...}Stores the ten scores that must be sorted.
int n = 10;Stores the number of elements, making the loops easier to understand and reuse.
printf("Initial Array...")Displays the original order before sorting changes the array.
for (i = 0; i < n - 1; i++)The outer loop controls how many passes are made. Bubble Sort needs n-1 passes in the basic version.
for (j = 0; j < n - 1; j++)The inner loop walks through neighboring pairs.
students[j] > students[j + 1]Checks whether the adjacent pair is in descending order. If so, swapping makes that pair ascending.
temp = students[j]Temporarily saves the left value so it is not lost when the assignment happens.
students[j] = students[j + 1]Moves the smaller right-hand value to the left.
students[j + 1] = tempPuts the original left value into the right position.

4. Think through one example

A small example [5, 2, 4]: compare 5 and 2 → swap → [2,5,4]; compare 5 and 4 → swap → [2,4,5]. Next pass confirms the order.

5. Rebuild recipe

  1. Print the initial array.
  2. Use an outer loop for repeated passes.
  3. Use an inner loop to compare adjacent elements.
  4. If left > right, swap them.
  5. After the passes, print the final array.
Lab 5

Binary Search

Problem 1

Search a Sorted Array Using Binary Search

Problem statement: Search for a key in the sorted array {1, 3, 9, 17, 25, 29, 43, 55, 83, 99}. Print its index if found; otherwise report that it does not exist.

1. How to recognize the solution from the question

  • The key phrase is 'sorted array'. That is the condition that allows Binary Search.
  • Instead of checking every element, repeatedly check the middle of the current search range.
  • If the key is larger than the middle value, everything to the left of the middle can be discarded.
  • If the key is smaller, everything to the right can be discarded.
  • Three variables describe the current search range: low, high, and mid.

2. Code

#include <stdio.h>

int main() {
    int arr[10] = {1, 3, 9, 17, 25, 29, 43, 55, 83, 99};
    int low, high, mid, flag = 0, key, index = -1;

    printf("Enter the key you want to search: ");
    scanf("%d", &key);

    low = 0;
    high = 9;

    while(low <= high) {
        mid = (low + high) / 2;

        if(key == arr[mid]) {
            flag = 1;
            index = mid;
            break;
        }
        else if(key > arr[mid]) {
            low = mid + 1;
        }
        else {
            high = mid - 1;
        }
    }

    if(flag == 1) {
        printf("Element %d is found at index %d\n", key, index);
    }
    else {
        printf("Element %d is not found in the array\n", key);
    }

    return 0;
}

3. What each important part does

Code / partWhy it is written this way
low = 0;The search initially begins at the first index.
high = 9;Because the array has 10 elements, its last valid index is 9.
while(low <= high)As long as there is at least one possible index remaining, continue searching.
mid = (low + high) / 2;Finds the middle index of the current search range using integer division.
if(key == arr[mid])If the middle value equals the key, the search is complete.
flag = 1;Marks the search as successful.
index = mid;Stores the matching index so it can be printed after the loop.
else if(key > arr[mid])Because the array is sorted, a larger key must be to the right of mid. Everything from low through mid can be discarded.
low = mid + 1;Moves the lower boundary past the middle.
high = mid - 1;When the key is smaller, discard mid and everything to its right by moving the upper boundary left.
flag == 1After the loop, this tells the program whether a match was found.

4. Think through one example

For key 29: low=0, high=9 → mid=4 (25); 29 is larger → low=5 → mid=7 (55); 29 is smaller → high=6 → mid=5 (29), found.

5. Rebuild recipe

  1. Make sure the array is sorted.
  2. Set low to 0 and high to the last index.
  3. While low <= high, calculate mid.
  4. Compare key with arr[mid].
  5. Equal: found.
  6. Greater: search right half with low = mid + 1.
  7. Smaller: search left half with high = mid - 1.
  8. If the loop finishes, the key was not found.
