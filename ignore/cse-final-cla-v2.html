1. Karnaugh Maps (K-Maps)

K-Map = a picture of a truth table laid out in a grid so that neighbouring cells differ by exactly one variable. Grouping neighbouring 1s lets you cancel variables and get a shorter Boolean expression.

Minterm = an AND term containing every variable once (e.g. x′y′z). Each row of the truth table is one minterm, called m0, m1, m2 and so on (the number is the binary value of the row). Literal = one variable or its complement.

Three-variable map

Key trick: columns go 00, 01, 11, 10 (Gray code, not normal binary). This guarantees neighbours differ by one bit. The left and right edges also count as neighbours (the map wraps around).

Example 1: F(A,B,C) = Σ(1,2,3,5,7)

Blue group (column pair 01 and 11 in both rows) = C. Red group (m2, m3) = A′B. So F = A′B + C.

Example 2: F(x,y,z) = Σ(3,4,6,7), wrap-around

m4 (100) and m6 (110) differ in one bit so they are neighbours across the edge. F = YZ + XZ′.

Four-variable map

Example 3: F(w,x,y,z) = Σ(0,1,2,4,5,6,8,9,12,13,14)

F = Y′ + W′Z′ + XZ′. Y′ takes the 8 cells in columns 00 and 01. The two Z′ groups use the four corner/edge wrap-arounds.

Grouping rules

  • Groups must be rectangles of size 1, 2, 4, 8, 16 (powers of 2).
  • Make groups as big as possible and use as few groups as possible. Overlap is allowed.
  • Every 1 must be in at least one group. Each group becomes one product term (keep variables that do not change inside the group).

Five variables

Use two 4-variable maps stacked (A=0 and A=1). Cells in the same position of both maps are neighbours too. Slide result: F(A,B,C,D,E) = BE + AD′E + A′B′E′.

Completely specified function = output is defined for every input combination. Incompletely specified = some inputs have no defined output (see next section).

2. Don't-Care Conditions and Product-of-Sums

Don't care (X) = an input combination that never happens or whose output does not matter. You may treat each X as 1 (if it helps make a bigger group) or as 0 (ignore it). Never make a group made only of X's.

Example: F = Σ(1,3,7,11,15), d = (0,2,5)

X's at m0 and m2 let the top row become one group of 4: F = W′X′ + YZ. (Using m5 instead gives F = W′Z + YZ, also valid and same cost.)

Product of Sums (POS)

Steps: (1) group the 0s to get F′ as a sum of products; (2) complement F′ using DeMorgan's law to get F as a product of sums.

F′ = AB + CD + BD′. Apply DeMorgan: F = (A′+B′)(C′+D′)(B′+D).

3. NAND and NOR Implementation

Universal gate = a gate that alone can build AND, OR and NOT, hence any circuit. NAND and NOR are both universal. NAND = AND followed by NOT. NOR = OR followed by NOT.

NOT: tie both NAND inputs together. AND: NAND then NAND-as-NOT. OR: invert each input with a NAND, then NAND them: (x′y′)′ = x + y.

Easy technique: AND-OR becomes NAND-NAND

  1. Simplify to sum of products with a K-Map.
  2. Complement the whole function twice, then use DeMorgan on the inner bar. Each product becomes a NAND, and the final OR becomes a NAND.

Example AB + CD becomes ((AB)′·(CD)′)′. Two-level AND-OR = two-level NAND-NAND (the double inverters cancel out).

Example: F(x,y,z) = Σ(1,2,3,4,5,7)

K-Map gives F = xy′ + x′y + z. Then F = ((xy′)′ (x′y)′ (z)′)′.

Multilevel NAND

If the function is not in sum-of-products form (e.g. F = A(CD + B) + BC′) you get 3+ levels. Rule: convert every AND/OR to NAND, and wherever a NAND feeds a gate that expects the opposite level, add an inverter. Alternating levels of AND-type and OR-type gates is the clean way to see it.

NOR implementation (the dual)

Everything is mirrored: NOR is the dual of NAND. Simplify to product of sums (group the 0s), then complement twice. Example: (A+B)(C+D)E becomes ((A+B)′ + (C+D)′ + E′)′. NOR as NOT: tie inputs. NOR-NOR gives OR-AND (product of sums).

4. Exclusive-OR (XOR), Odd/Even Functions and Parity

XOR: output is 1 when the inputs are different. x⊕y = xy′ + x′y. XNOR (equivalence): output is 1 when inputs are the same: (x⊕y)′ = xy + x′y′.

Identities: x⊕0 = x; x⊕1 = x′; x⊕x = 0; x⊕x′ = 1; x⊕y′ = x′⊕y = (x⊕y)′. XOR is commutative (A⊕B = B⊕A) and associative ((A⊕B)⊕C = A⊕(B⊕C)).

XOR built from 4 NAND gates (the shared first NAND saves gates).

Odd and Even functions

An n-variable XOR is an odd function: it equals 1 for the 2ⁿ/2 minterms that have an odd number of 1s. Three variables: A⊕B⊕C = Σ(1,2,4,7). Four variables: A⊕B⊕C⊕D = Σ(1,2,4,7,8,11,13,14). The complement of an odd function is an even function.

Checkerboard pattern = odd function. No two 1s are adjacent, so a K-Map cannot simplify it.

Parity generation and checking

A parity bit is an extra bit added so the total count of 1s is always even (even parity), to catch single-bit errors.

  • Generator (3-bit message x,y,z): P = x⊕y⊕z. P = 1 exactly when the message has an odd number of 1s, so the total becomes even.
  • Checker (4 bits received x,y,z,P): C = x⊕y⊕z⊕P. C = 1 means an odd number of 1s arrived, i.e. an error.

5. Combinational Circuits (Chapter 4 basics)

Combinational circuit: output depends only on the present inputs (no memory). Sequential circuit: also has storage elements, so output depends on inputs and stored state.

A combinational block has n inputs and m outputs. Analysis = given a circuit, find its function (Boolean expression or truth table). Design = given a function, build the circuit.

Design procedure

  1. Find the number of inputs and outputs.
  2. Write the truth table.
  3. Simplify each output (K-Map).
  4. Draw the circuit and verify.

Example: BCD to Excess-3 converter

Input ABCD is a BCD digit (0 to 9), output wxyz = value + 3. Inputs 10 to 15 never occur, so they are don't-cares. K-Maps give:

w = A + BC + BD   x = B′C + B′D + BC′D′   y = C′D′ + CD   z = D′

Example check: BCD 0101 (5) gives 1000 (8). Yes, 5 + 3 = 8.

6. Decoders

Q1Decoder: definition and circuit

Decoder = a combinational circuit that converts n input lines into up to 2ⁿ unique output lines. For each input code exactly one output is 1 (like one lamp lighting up). Each output is a minterm of the inputs.

Circuit: one AND gate per output. The inputs and their complements (made with NOT gates) feed the ANDs.

Q23-to-8 Decoder (very important)

3 inputs (I2 I1 I0), 8 outputs (Y0 to Y7). Output Yk is 1 only when the input binary number equals k. Block diagram, circuit and truth table:

Equations: Y0 = I2′I1′I0′, Y1 = I2′I1′I0, Y2 = I2′I1I0′, Y3 = I2′I1I0, Y4 = I2I1′I0′, Y5 = I2I1′I0, Y6 = I2I1I0′, Y7 = I2I1I0. Eight 3-input AND gates and 3 inverters.

Q3Enable control

Enable (E) = an on/off switch for the decoder. If E = 0, all outputs are 0 no matter what the inputs are. If E = 1, it works normally. Circuit change: add E as an extra input to every AND gate.

Active-high vs active-low: an active-high decoder makes the selected output 1 (others 0). An active-low decoder (built with NAND gates) makes the selected output 0 and all others 1. Same idea, inverted outputs.

Decoder expansion

Build a 3-to-8 from two 2-to-4 decoders with enable: I2 selects which one is on. Lower decoder gets E = I2′ (outputs Y0 to Y3), upper gets E = I2 (outputs Y4 to Y7). I1 and I0 go to both.

Implementing a function with a decoder

The decoder makes every minterm, so just OR the minterms you need. Full adder: S(x,y,z) = Σ(1,2,4,7) and C(x,y,z) = Σ(3,5,6,7). Use a 3-to-8 decoder with inputs x,y,z, feed Y1,Y2,Y4,Y7 into one OR gate (sum), and Y3,Y5,Y6,Y7 into another OR gate (carry).

7. Encoders

Q4Encoder: definition and circuit

Encoder = does the reverse of a decoder. It has 2ⁿ (or fewer) input lines and n output lines, and outputs the binary code of whichever input is active. Constraint: only one input may be 1 at a time.

Each output is an OR gate collecting the inputs whose code has a 1 in that bit position.

Q5Octal-to-Binary encoder (8-to-3)

Y0 = I1 + I3 + I5 + I7   Y1 = I2 + I3 + I6 + I7   Y2 = I4 + I5 + I6 + I7

I0 is not connected: when all inputs are 0 the output is 000 anyway. (Problem: this cannot tell "I0 active" from "nothing active". Priority encoders fix this with a valid bit V.)

Priority encoder

If several inputs are 1 at once, the highest-numbered input wins. Extra output V (valid) = 1 if any input is 1.

8. Multiplexers (MUX)

Q6Multiplexer: definition, block diagram, circuit

Multiplexer (MUX, "data selector") = a combinational circuit that selects one of 2ⁿ input lines and sends it to a single output. n select lines choose which input. Think of a railway switch with many tracks in and one track out.

Q74-to-1 MUX: block diagram, truth table, circuit diagram

Y = S1′S0′I0 + S1′S0I1 + S1S0′I2 + S1S0I3. Circuit: a 2-to-4 decoder on S1,S0 gates each data input through an AND, and an OR combines them.

MUX expansion

A 4-to-1 MUX from three 2-to-1 MUXes: two first-level MUXes (select S0) and one second-level MUX (select S1). Likewise an 8-to-1 MUX = two 4-to-1 MUXes + one 2-to-1 MUX (S2 picks which one).

Quad 2-to-1 MUX: four 2-to-1 MUXes sharing one select line S, so you can pick between two whole 4-bit words (A3..A0 or B3..B0). A shared enable E can switch all outputs off.

Three-state (tri-state) gates

A tri-state buffer has a control C: C = 1 passes A to Y; C = 0 gives Hi-Z (high impedance, "disconnected"). Several tri-state outputs can share one wire if only one is enabled, which is another way to build a MUX.

9. Implementing Functions with Multiplexers

Q8 Rule: an (n+1)-variable function fits a 2ⁿ-to-1 MUX. Use n variables as selectors and the remaining variable (or 0, 1) on the input lines. There are 2 procedures; learn both.

Procedure 1 (table method): F(A,B,C) = Σ(1,3,5,6)

Version a: B,C are selectors, A goes to input lines.

  1. Write columns I0..I3 (= BC = 00,01,10,11).
  2. Row 1: minterms where A′ (0,1,2,3). Row 2: minterms where A (4,5,6,7).
  3. Circle the minterms of F.
  4. For each column: none circled = 0; both circled = 1; only bottom circled = A; only top circled = A′.

Version b: A,B are selectors, C goes to input lines (same function). Top row = C′ minterms (0,2,4,6), bottom = C minterms (1,3,5,7). Result: I0 = C, I1 = C, I2 = C, I3 = C′.

Procedure 2 (truth table method)

  1. Write the full truth table.
  2. The first n variables (all except the last) go to the select lines.
  3. For each select combination, see what F equals as a function of the last variable: it will be 0, 1, the variable, or its complement.
  4. Connect those values to the data inputs in order.

Example A: F(x,y) = Σ(0,1,3). Table F = 1,1,0,1 for xy = 00,01,10,11. Selectors x,y, inputs 1,1,0,1 (a 4-to-1 MUX with constants).

Example B: F(x,y,z) = Σ(1,2,6,7). Selectors x,y. For xy=00: F = z. xy=01: F = z′. xy=10: F = 0. xy=11: F = 1. Only a 4-to-1 MUX needed instead of 8-to-1.

Example C: F(A,B,C,D) = Σ(1,3,4,11,12,13,14,15). Selectors A,B,C (8-to-1 MUX), D on inputs. ABC=000: D; 001: D; 010: D′; 011: 0; 100: 0; 101: D; 110: 1; 111: 1.

Which one when? Procedure 2 always uses the last variable on the input lines. If you need a first or middle variable on the input lines (like A in version a), use Procedure 1.

10. Demultiplexers (DEMUX)

Q9Demultiplexer: 1 input to 2ⁿ outputs

Demultiplexer = the reverse of a MUX. It takes one input line and directs it to one of 2ⁿ output lines, chosen by n select lines. The unselected outputs stay 0.

Q10DEMUX and Decoder: make both (they are the same circuit!)

A decoder with an enable input works as a demultiplexer: use the enable E as the data input I and the decoder inputs as the select lines S1,S0. When the data I = 1 it appears on the selected output; when I = 0 everything is 0.

Quick Glossary

  • SOP: sum of products (ANDs ORed together). POS: product of sums (ORs ANDed together).
  • Dual: swap AND with OR and 0 with 1. NOR is the dual of NAND.
  • Select line: input that chooses which data line is used. Enable: input that turns the circuit on or off.
  • Hi-Z: high impedance, the output is electrically disconnected.
  • Sizes: decoder n to 2ⁿ, encoder 2ⁿ to n, MUX 2ⁿ to 1 (n selects), DEMUX 1 to 2ⁿ (n selects).
