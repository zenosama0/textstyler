5.2

Mean, Variance & Standard Deviation of a Probability Distribution

What is the Mean (Expected Value)?

The mean of a probability distribution - also called the expected value - tells you the theoretical average outcome if you repeated the experiment an infinite number of times. It is NOT the average of the x-values alone. You must weight each x-value by how likely it is to happen. Think of it as a weighted balance point: outcomes that are more probable pull the average toward them more strongly. It is written as μ (mu) or E(X).

Formula - Mean:
μ = Σ [ X · P(X) ]

Multiply each outcome by its probability, then add everything up.
What is Variance and Standard Deviation?

Variance measures how spread out the outcomes are around the mean. A high variance means outcomes are scattered far from the mean; a low variance means they cluster closely around it. Standard deviation is just the square root of the variance - it puts the spread back into the same units as the original data, making it easier to interpret.

Formula - Variance:
σ² = Σ [ X² · P(X) ] - μ²

Formula - Standard Deviation:
σ = √σ²
Worked Example - Rolling a die (outcomes 1-6, each P = 1/6, μ = 3.5)

Step 1 - Find σ²: Square each outcome, multiply by its probability, add them all up, then subtract μ².

σ² = (1²·1/6 + 2²·1/6 + 3²·1/6 + 4²·1/6 + 5²·1/6 + 6²·1/6) - (3.5)² = (1 + 4 + 9 + 16 + 25 + 36)/6 - 12.25 = 91/6 - 12.25 = 15.167 - 12.25 = 2.917 ≈ 2.9

Step 2 - Find σ:

σ = √2.9 ≈ 1.7

σ² = 2.9, σ = 1.7

5.3

The Binomial Distribution

What is a Binomial Experiment?

A binomial experiment is a special type of probability experiment that has exactly four properties that must ALL be true at the same time. First, there must be a fixed number of trials - you decide in advance how many times you will repeat the experiment. Second, each trial can only have two possible outcomes, which we call "success" and "failure" (success does NOT mean something positive happened - it just means the outcome you are counting). Third, the trials must be independent, meaning the result of one trial does not affect any other. Fourth, the probability of success must stay the same for every single trial.

4 Requirements (memorize these):
1. Fixed number of trials (n)
2. Each trial = only 2 outcomes (success / failure)
3. Trials are independent
4. Probability of success (p) is the same each trial
Key Symbols
n
Number of trials
X
Number of successes (can be 0, 1, 2, ... n)
p
Probability of success on any one trial
q
Probability of failure = 1 - p
Binomial Probability Formula
P(X) = [ n! / ((n-X)! · X!) ] · p^X · q^(n-X)
Worked Example - Survey on Employment

30% of teens get spending money from part-time jobs. 5 teens selected. Find P(at least 3 have part-time jobs).

"At least 3" means X = 3, 4, or 5. Calculate each and add.

n = 5, p = 0.30, q = 0.70

P(3) = [5! / (2!3!)] · (0.30)³ · (0.70)² = 10 · 0.027 · 0.49 = 0.132 P(4) = [5! / (1!4!)] · (0.30)⁴ · (0.70)¹ = 5 · 0.0081 · 0.70 = 0.028 P(5) = [5! / (0!5!)] · (0.30)⁵ · (0.70)⁰ = 1 · 0.00243 · 1 = 0.002 P(X ≥ 3) = 0.132 + 0.028 + 0.002 = 0.162

There is a 16.2% chance that at least 3 of the 5 teens have part-time jobs.

Mean, Variance & SD for Binomial - Much Easier Formulas!
Mean: μ = n · p
Variance: σ² = n · p · q
Standard Deviation: σ = √(n · p · q)
Example - Coin tossed 4 times

n = 4, p = 0.5, q = 0.5

μ = 4 × 0.5 = 2 σ² = 4 × 0.5 × 0.5 = 1 σ = √1 = 1
6.2

Standard Normal Distribution - Finding Areas

What is the Normal Distribution?

The normal distribution is a continuous, bell-shaped, symmetric curve that describes how many real-world variables are distributed - things like heights, test scores, and blood pressure. It is described entirely by two numbers: its mean (μ), which controls where the center of the bell sits, and its standard deviation (σ), which controls how wide or narrow the bell is. A larger σ makes the curve wider and flatter; a smaller σ makes it taller and more narrow. The total area under the curve always equals 1 (or 100%), and the mean, median, and mode are all equal and sit at the center.

The standard normal distribution is a special version with μ = 0 and σ = 1. We use it by converting any normal variable into a z-score.

Key Properties:
- Bell-shaped, symmetric about the mean
- Mean = Median = Mode (all at center)
- Total area under curve = 1.00 (100%)
- Curve never touches the x-axis
- 68% of data within 1σ, 95% within 2σ, 99.7% within 3σ
The z-score Formula

A z-score tells you how many standard deviations a value is above or below the mean. A positive z means above the mean; a negative z means below the mean. Once you have a z-score, you look up the area (probability) in Table E.

z = (X - μ) / σ
3 Cases for Finding Areas (Table E always gives LEFTWARD area)
Case 1
Area to the LEFT of z - just look up z in Table E. That value is your answer.
Case 2
Area to the RIGHT of z - look up z in Table E, then subtract from 1.0000.
Case 3
Area BETWEEN two z values - look up both z values in Table E, then subtract the smaller area from the larger area.
Case 1 - Left of z = 2.09

Look up 2.0 in left column, 0.09 in top row.

Table E gives: 0.9817

98.17% of the area is to the left of z = 2.09.

Case 2 - Right of z = -1.14
Table E for z = -1.14 gives: 0.1271 Right area = 1.0000 - 0.1271 = 0.8729

87.29% of the area is to the right of z = -1.14.

Case 3 - Between z = -1.35 and z = 1.62
Table E for z = 1.62 gives: 0.9474 Table E for z = -1.35 gives: 0.0885 Area between = 0.9474 - 0.0885 = 0.8589

85.89% of the area falls between these two z values.

6.3

Applications of the Normal Distribution

Converting a Real-World Value to a z-score

Most real-world variables are NOT the standard normal (they have means and standard deviations other than 0 and 1). To use Table E, you must first convert the raw value (X) into a z-score using the formula. Then you work with the z-score exactly as in Section 6.2.

3-Step Procedure for Any Normal Curve Problem:
Step 1 - Draw the normal curve and shade the area you want
Step 2 - Convert X to z using z = (X - μ) / σ
Step 3 - Find the area using Table E (apply Case 1, 2, or 3)
Worked Example - Blood Volume

Adults average 5.2 liters of blood, σ = 0.3. What percent have LESS than 5.4 liters?

Step 1: Shade area to the LEFT of X = 5.4 (that's Case 1).

Step 2: Convert to z.

z = (5.4 - 5.2) / 0.3 = 0.2 / 0.3 = 0.67

Step 3: Look up z = 0.67 in Table E.

Table E → 0.7486

74.86% of adults have less than 5.4 liters of blood.

Working Backwards - Finding X from a Probability

Sometimes the exam gives you the area (probability) and asks you to find the actual X value. You reverse the process: look up the area in Table E to find the z-score, then use the rearranged formula to find X.

Reverse Formula (finding X from z):
X = z · σ + μ
Worked Example - Police Academy

Candidates must score in TOP 10%. Test: μ = 200, σ = 20. Find lowest qualifying score.

Step 1: Top 10% means 90% to the LEFT. Find z for area 0.9000 in Table E.

Closest area in Table E: 0.8997 → z = 1.28

Step 2: Find X.

X = 1.28 × 20 + 200 = 25.6 + 200 = 225.6

A candidate must score at least 226 to qualify.

7.1

Confidence Intervals for the Mean (σ Known)

What is a Confidence Interval?

A confidence interval is a range of values that we believe contains the true population mean, with a certain level of confidence. Instead of saying "the mean is exactly 54," we say "we are 95% confident the true mean is somewhere between 52.3 and 55.7." This is more honest because we know our sample is not perfect. The confidence level (typically 90%, 95%, or 99%) tells you: if you repeated this sampling process many times, that percentage of the resulting intervals would actually capture the true population mean. A higher confidence level means a wider interval - you are trading precision for certainty.

A point estimate is a single number that estimates the population mean - the sample mean (X̄). But it says nothing about how accurate it is, which is why we prefer confidence intervals.

Formula for Confidence Interval (σ known):
X̄ - z(α/2) · (σ/√n) < μ < X̄ + z(α/2) · (σ/√n)

z(α/2) critical values:
90% confidence → z = 1.65
95% confidence → z = 1.96
99% confidence → z = 2.58
Margin of Error (E)

The margin of error is the "± part" of a confidence interval. It tells you the maximum likely difference between your sample mean and the true population mean.

E = z(α/2) · (σ / √n)
Worked Example - Days to Sell a Car

Sample of 50 cars, X̄ = 54 days, σ = 6.0. Find 95% CI.

E = 1.96 × (6.0 / √50) = 1.96 × 0.849 = 1.66 ≈ 1.7 Lower: 54 - 1.7 = 52.3 Upper: 54 + 1.7 = 55.7 CI: 52.3 < μ < 55.7

We are 95% confident the true mean is between 52.3 and 55.7 days.

Finding Minimum Sample Size

Use this formula when you need to know how large your sample must be to achieve a certain margin of error E. Always round UP to the next whole number.

n = ( z(α/2) · σ / E )²
Example - River Depth (99% CI, E = 2 feet, σ = 4.33)
n = (2.58 × 4.33 / 2)² = (5.57)² = 31.0 → round UP → n = 32

Need at least 32 measurements.

7.2

Confidence Intervals for the Mean (σ Unknown) - t-distribution

Why Use the t-distribution?

In real life, you almost never know the true population standard deviation (σ). When σ is unknown, you must use the sample standard deviation (s) instead. However, substituting s for σ introduces extra uncertainty, which means your critical values need to be slightly larger to compensate. This is where the t-distribution comes in. It looks like the normal bell curve but has heavier tails (wider spread), especially for small samples. As the sample size grows, the t-distribution approaches the standard normal distribution. The exact shape depends on degrees of freedom, which equals n - 1.

When to use t instead of z:
σ is UNKNOWN → use t-distribution with s in the formula

Degrees of Freedom: d.f. = n - 1

Formula:
X̄ - t(α/2) · (s/√n) < μ < X̄ + t(α/2) · (s/√n)
How to Find t(α/2) from Table F
  • 1
    Calculate degrees of freedom: d.f. = n - 1
  • 2
    Find d.f. in the LEFT column of Table F
  • 3
    Find the correct confidence level % in the top row labeled "Confidence Intervals"
  • 4
    The number at the intersection is your t(α/2) value
If d.f. falls between two table values (e.g., 68 falls between 65 and 70), always round DOWN to the smaller value. This is the conservative approach.
Worked Example - Infant Growth

Sample of 10 children, X̄ = 9.8 inches, s = 0.96 inches. Find 95% CI.

d.f. = 10 - 1 = 9. Look up 9 d.f. at 95% in Table F → t = 2.262.

E = 2.262 × (0.96 / √10) = 2.262 × 0.3036 = 0.687 ≈ 0.69 Lower: 9.8 - 0.69 = 9.11 Upper: 9.8 + 0.69 = 10.49 CI: 9.11 < μ < 10.49

We are 95% confident the true mean first-year growth is between 9.11 and 10.49 inches.

Quick Decision: z or t?
σ known
Use z with σ in the formula (Section 7.1)
σ unknown, n ≥ 30
Use t with s in the formula
σ unknown, n < 30
Use t with s, AND the population must be approximately normal
8.2

z Test for a Mean

What is Hypothesis Testing?

Hypothesis testing is a formal method for deciding whether a claim about a population is supported by sample data. You start with a null hypothesis (H₀), which is the "status quo" - the assumption that nothing unusual has happened. You also form an alternative hypothesis (H₁), which is the claim you are testing. You then collect data and calculate a test statistic. If the test statistic is extreme enough (falls in the critical region), you reject the null hypothesis. If not, you fail to reject it. You can NEVER prove H₀ true - you can only say there is or is not enough evidence against it.

H₀ (Null): The claim being tested, assumed true initially (uses =)
H₁ (Alternative): The claim you want to support (uses >, <, or ≠)

The z test is used when σ is KNOWN.

z = (X̄ - μ) / (σ / √n)
Critical Values for z Tests
Two-tailed
H₁: μ ≠ value → critical values are ±z(α/2)
Right-tailed
H₁: μ > value → critical value is +z(α)
Left-tailed
H₁: μ < value → critical value is -z(α)
Common Critical Values
α = 0.05
Two-tailed: ±1.96 | Right: +1.65 | Left: -1.65
α = 0.01
Two-tailed: ±2.58 | Right: +2.33 | Left: -2.33
α = 0.10
Two-tailed: ±1.65 | Right: +1.28 | Left: -1.28
5-Step Process (Traditional Method)
  • 1
    State H₀ and H₁ - identify which is the claim
  • 2
    Find the critical value(s) - based on α and whether it is one-tailed or two-tailed
  • 3
    Compute the test value - z = (X̄ - μ) / (σ/√n)
  • 4
    Make the decision - if the test value falls IN the critical region, REJECT H₀. If not, do NOT reject H₀.
  • 5
    Summarize - state in plain words whether there is or is not enough evidence to support the claim
Worked Example - IQ Test (Right-tailed, α = 0.05)

Claim: local students have higher IQ than state average of 101.5. Sample: n = 30, X̄ = 106.4, σ = 15.

Step 1: H₀: μ = 101.5 | H₁: μ > 101.5 (claim)

Step 2: Right-tailed, α = 0.05 → critical value = +1.65

Step 3:

z = (106.4 - 101.5) / (15 / √30) = 4.9 / 2.739 = 1.79

Step 4: 1.79 > 1.65, so it IS in the critical region → REJECT H₀

Step 5: There IS enough evidence to support the claim that local students have a higher IQ.

P-value Method (alternative approach)

The P-value is the probability of getting a sample result at least as extreme as the one observed, assuming H₀ is true. If the P-value is very small (smaller than α), it means your result would be very unlikely under H₀, so you reject H₀. If P-value is large, you fail to reject.

Decision rule:
If P-value ≤ α → REJECT H₀
If P-value > α → Do NOT reject H₀

For right-tailed: P-value = 1 - (Table E area for z)
For left-tailed: P-value = Table E area for z
For two-tailed: P-value = 2 × (tail area)
8.3

t Test for a Mean (σ Unknown)

When Do You Use the t Test?

Use the t test instead of the z test whenever the population standard deviation (σ) is unknown - which is most of the time in real life. When σ is unknown, you use the sample standard deviation (s) in the formula. The t-distribution has slightly heavier tails than the normal distribution, so the critical values from Table F are slightly larger than z critical values. The shape of the t-distribution depends on degrees of freedom (d.f. = n - 1): the smaller the sample, the heavier the tails and the larger the critical values required.

t Test Formula:
t = (X̄ - μ) / (s / √n)

Degrees of freedom: d.f. = n - 1

Use this when: σ is unknown AND (n ≥ 30 OR population is approximately normal)
5-Step Process (same structure as z test)
  • 1
    State H₀ and H₁ - identify which contains the claim
  • 2
    Find critical t value(s) from Table F using d.f. = n - 1 and the correct column for α and tail type
  • 3
    Compute t test value → t = (X̄ - μ) / (s/√n). If given raw data, calculate X̄ and s first.
  • 4
    Make decision - if test t falls IN critical region, REJECT H₀
  • 5
    Summarize the result in plain language
Worked Example - Hospital Infections (Two-tailed, α = 0.05)

Claim: average infections per week = 16.3. Sample: n = 10, X̄ = 17.7, s = 1.8.

Step 1: H₀: μ = 16.3 (claim) | H₁: μ ≠ 16.3

Step 2: d.f. = 9, two-tailed, α = 0.05 → Table F gives t = ±2.262

Step 3:

t = (17.7 - 16.3) / (1.8 / √10) = 1.4 / 0.569 = 2.460

Step 4: 2.460 > 2.262, so it IS in the critical region → REJECT H₀

Step 5: There IS enough evidence to reject the claim that the mean number of infections is 16.3.

Worked Example - Nurse Salaries (Left-tailed, α = 0.10)

Claim: starting salary for nurse practitioners is LESS than $79,500. n = 8, X̄ = $75,150, s = $6,937.68

Step 1: H₀: μ = $79,500 | H₁: μ < $79,500 (claim)

Step 2: d.f. = 7, left-tailed, α = 0.10 → Table F gives t = -1.415

Step 3:

t = (75,150 - 79,500) / (6937.68 / √8) = -4350 / 2452.6 = -1.773

Step 4: -1.773 < -1.415, so it IS in the critical region → REJECT H₀

Step 5: There IS enough evidence to support the claim that the starting salary is less than $79,500.

z vs. t - Quick Decision Chart
σ known
Use z test regardless of sample size (as long as n ≥ 30 or population is normal)
σ unknown, n ≥ 30
Use t test with s in the formula
σ unknown, n < 30
Use t test, but population MUST be approximately normally distributed
The structure of both the z test and the t test is identical - same 5 steps, same decision rule. The only difference is which table you use (Table E for z, Table F for t) and which formula you plug into. Master the 5 steps and you can handle both.
